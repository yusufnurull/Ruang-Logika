Mesin Pembalik String Otomatis

Prinsip Last In, First Out (LIFO) pada Stack menjadikannya struktur data tercepat untuk membalik urutan data. Masukkan sebuah kata, masukkan huruf-hurufnya satu per satu ke dalam tumpukan, lalu keluarkan semua untuk melihat hasil kata terbaliknya secara instan!

info Langkah Operasi: 1. Ketik kata pada input (maksimal 8 huruf). 2. Klik Push Huruf → Karakter masuk ke Stack. 3. Klik Pop Semua → Huruf keluar terbalik sempurna.

02 Misi Validasi • Syntax Checker +50 XP

Detektor Kurung Siku Seimbang (Balanced Brackets)

Compiler bahasa pemrograman (seperti Python, C++, dan JavaScript) menggunakan Stack untuk memverifikasi apakah setiap tanda kurung buka (, [, { berpasangan dengan kurung tutup yang tepat.

Aturan Kerja Parser: • Kurung buka di-Push ke Stack. • Kurung tutup men-Pop puncak stack dan membandingkan kecocokan. • Jika di akhir Stack kosong & tidak ada salah pasangan = SINTAKS VALID!

03 Misi Queue • FIFO Kafetaria +50 XP

Simulator Antrean Loket Pemesanan (FIFO)

Kafetaria sekolah melayani siswa menggunakan sistem nomor tiket terurut. Buktikan bahwa urutan siswa yang mengambil pesanan (Dequeue) selalu sama persis dengan urutan saat mereka mengantre pertama kali (Enqueue).

Prinsip Keadilan Pelayanan: • Siswa di ujung FRONT dilayani lebih dulu. • Siswa baru tiba mengantre di posisi REAR.
